## 一、今日完成内容

### 1. 多 Agent 协作调查框架

完成 AML Investigation Agent 从单 Agent 到 Multi-Agent 架构升级：

- Supervisor Agent：主控和动态任务调度
- Rule Agent：规则命中分析
- Graph Agent：Neo4j 资金路径和循环交易分析
- Transaction Agent：DWD 交易和账户画像分析
- Report Agent：汇总证据并生成调查报告
- 新增 `investigation_task` 任务审计表
- 支持任务状态：`WAITING`、`RUNNING`、`COMPLETED`、`FAILED`
- 根据规则命中和账户画像动态选择 Agent，不固定执行全部任务

### 2. 可解释风险分析层

新增 `explainability/` 模块：

- `evidence_builder.py`：构建统一证据链
- `risk_explainer.py`：生成风险原因和证据说明
- `score_explainer.py`：拆解规则、图谱、交易行为和账户画像评分

证据来源包括：

- APP Alert 和 Alert Evidence
- Neo4j TRANSFER 图谱
- DWD 交易明细
- DWS 账户风险画像

### 3. 反事实解释能力

新增 `counterfactual/` 模块：

- `analyzer.py`：组织反事实分析
- `risk_simulator.py`：模拟移除交易或风险因素后的分数变化
- `counterfactual_report.py`：生成反事实报告章节

特点：

- 只进行内存模拟
- 不修改真实交易数据、Alert、SQLite 或 Neo4j
- 输出移除因素、移除后分数、影响分数和证据解释

### 4. 调查报告优化

报告统一为七个章节：

1. 案件基本信息
2. 风险结论
3. 风险原因分析
4. 证据链
5. 反事实分析
6. 人工审核建议
7. 免责声明

单 Agent 和 Multi-Agent 均已接入可解释性和反事实结果。

## 二、问题排查与修复

### Graph Agent 循环路径为空

发现原有普通 1–3 跳查询会排除回到起点的路径，导致循环交易结果始终为空。

已修复为独立 Neo4j 闭环 Cypher 查询：

```cypher
MATCH path = (source:Account {account_id: $account_id})-[:TRANSFER*3..8]->(source)
```

真实验证 `AL000001` 可返回循环路径。

### 报告生成时间不准确

报告原来使用预警创建时间作为生成时间，已修复为报告实际生成时间。
