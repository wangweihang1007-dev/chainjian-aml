# 自迭代第一阶段实现说明

## 已实现

`scripts/iteration_cycle.py` 已将 SOP 的第一阶段落地为一次可审计的离线任务：

1. 读取上一周期监控快照；
2. 采集数据质量、金额分布、规则命中量、预警量和审核统计；
3. 调用 `evaluation/evaluate_rules.py` 做离线评估；
4. 按 SOP 阈值诊断数据漂移、预警量漂移、审核反馈和 F1；
5. 输出 Markdown 提案和 JSON 结果，等待人工诊断、审批和发布。

## 运行

```powershell
python -m scripts.iteration_cycle
```

也可以指定提案目录：

```powershell
python -m scripts.iteration_cycle --proposal-dir docs/operations/iteration-proposals
```

## 安全边界

- 不自动修改规则、模型权重、风险等级或生产数据。
- 不自动发布，必须经过人工审批、回归测试和回滚方案确认。
- 评估标签只在离线评估链路使用，不进入推理、图谱或 Agent 工具。
- Neo4j 不可用时，任务会生成明确的 `OFFLINE_EVALUATION_UNAVAILABLE` 红色信号，不伪造评估结果。

## 当前验证

项目测试：`17 passed`。本地没有配置 Neo4j 密码时，自迭代任务仍能生成提案，但会把图谱依赖问题标记为红色信号，供人工处理。
